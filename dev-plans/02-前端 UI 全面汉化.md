# 02 前端 UI 全面汉化

| 项 | 内容 |
|---|---|
| 需求编号 | REQ-02 |
| 优先级 | P1（核心需求一） |
| 预估工作量 | 3-5 周 |
| 前置依赖 | 01 仓库基础 |

## 1. 需求说明

将 LiteLLM Admin UI（React + TypeScript + Next.js）中的硬编码英文文本全面替换为国际化内容，支持中/英双语切换。

**改造边界：** 仅汉化用户可见的界面文本（title、label、button、tooltip、placeholder 等），不涉及：
- API 字段名（`max_budget`、`tpm_limit` 等保持英文）
- 数据库列名与代码标识符
- 开发者文档与模块 README

### 3.2 组件改造方式 ✅

使用 `useTranslations` hook：

```tsx
"use client";
import { useTranslations } from "next-intl";

export default function LoginPage() {
  const translate = useTranslations("login");
  
  return (
    <div>
      <h1>{translate("title", "登录")}</h1>
      <input label={translate("username")} />
      <button>{translate("button", "登录")}</button>
    </div>
  );
}
```

## 5. 注意事项 ⚠️

1. **不可触碰清单：**
   - API 字段名（`max_budget`、`tpm_limit`）全部保持英文
   - 数据库列名与代码标识符
   - 日志级别与异常类型名

2. **Prisma 迁移红线：**
   - 只允许加 nullable 列，禁止 `UPDATE/DELETE/MERGE`

3. **企业版边界：**
   - `enterprise/` 目录不得修改
   - 自有功能不得依赖企业版 license 特性（SSO 等）

4. **UI 汉化冲突风险：**
   - UI 组件文件改动频繁，与上游同步时容易冲突
   - 建议按批次切分，每批完成后再合并到 develop
