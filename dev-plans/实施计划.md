**Git 分支**: `feat/error-i18n-backend`

#### 实施方案（外挂式，几乎零冲突）

```
litellm_cn/
├── locale/
│   ├── en.json          # 原文映射
│   └── zh-CN.json       # 译文映射（先收录高频报错 200-300 条）
├── translator.py        # translate_message(text, locale)
└── middleware.py        # FastAPI 响应中间件，改写 error.message
```

#### 挂载方式
在 `proxy_server.py` 添加 3 行 `[CN-FORK]` 标记的挂载点：

```python
# 在 general_settings 注册自定义钩子
from litellm_cn.middleware import install
install(app)
```

## 执行脚本

### 需求 01：仓库管理（持续运维）

每月同步上游的脚本：

```bash
#!/bin/bash
# sync-upstream.sh

cd "D:/project/litellm-cn"

echo "=== Sync upstream to main ==="
git checkout main
git fetch upstream
if git merge --ff-only upstream/main; then
    echo "✓ Main synced successfully"
    git push origin main
else
    echo "⚠ Upstream has non-fast-forward changes, manual merge needed"
fi

echo "=== Merge to develop ==="
git checkout develop
git merge main
echo "✓ Develop merged with main"
git status
```

### 需求 02+03：执行脚本（简化版）
