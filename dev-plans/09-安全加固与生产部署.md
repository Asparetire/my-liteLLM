# 09 安全加固与生产部署

| 项 | 内容 |
|---|---|
| 需求编号 | REQ-09 |
| 优先级 | P1 |
| 预估工作量 | 3-5 天 |
| 前置依赖 | 无（可与其他需求并行） |

## 1. 目标

LiteLLM 默认配置面向快速起步，不适合直接承载企业内部流量。本需求把网关加固到可上生产的状态，覆盖密钥管理、数据库、网络暴露面、部署形态四块。

## 2. 密钥与凭据管理

| 项 | 要求 |
|---|---|
| Master Key | 必须替换默认值，通过环境变量或 secret 管理注入，不落配置文件 |
| 提供商 API Key | 全部用 `os.environ/XXX` 引用；禁止明文写入 `config.yaml` |
| 数据库凭据 | 环境变量注入；不使用默认 `llmproxy` 弱口令 |
| 密钥轮换 | 制定轮换周期与流程，轮换后验证旧 key 失效 |
| 日志脱敏 | 确认请求日志不落明文 API Key（虚拟密钥在库中为哈希存储，注意不要在日志里打印原始 key） |

## 3. 数据库

| 项 | 要求 |
|---|---|
| 生产强制 Postgres | 弃用 SQLite（token 配额、并发预算校验依赖事务与并发能力） |
| 迁移演练 | Prisma 迁移在 proxy 启动时同步执行，升级前必须先备份 + 测试库演练 |
| 用量表增长 | `LiteLLM_SpendLogs` 增长快，提前规划分区/归档策略（用量统计也可改用日度汇总表，仓库已有 `LiteLLM_DailyUserSpend` 等汇总表） |
| 备份 | 数据库定期备份；至少保留可回滚到上一版本的窗口 |

## 4. 网络与暴露面

| 项 | 要求 |
|---|---|
| 管理接口保护 | `/key/*`、`/user/*`、`/team/*` 等管理端点仅对内网开放 |
| UI 访问控制 | 控制台入口限制来源 IP 或置于内网/VPN 后 |
| CORS | 收敛允许来源，不使用通配 |
| 回调白名单 | 限制 webhook / 日志回调目标地址 |
| 出网策略 | proxy 需访问各提供商 API，按需放行域名，不做全量出网 |
| TLS | 前置网关或反向代理终结 TLS，内部通信按需加密 |

## 5. 部署形态

| 项 | 要求 |
|---|---|
| 镜像自构建 | 基于仓库 Dockerfile 构建自有镜像，固定版本标签（不用 `latest`） |
| 编排 | 优先使用仓库已有的 `docker-compose.hardened.yml` 作为加固基线 |
| 实例数 | 至少双实例 + 前置负载均衡（无状态设计，但 Redis 需共享） |
| Redis | 必须共享外部 Redis（预算/限流/预留机制依赖它做跨实例协调） |
| 健康检查 | 配置 `/health/liveliness` 与 `/health/readiness` 探针 |
| 灰度 | 首次上线先切非核心业务流量，观察配额与计量准确后再全量 |

## 6. 权限与审计

- 使用 key/team/org 三层结构做最小权限分配，不共用 master key 做业务调用
- 为每个调用方分配独立虚拟密钥，便于用量归因（也是 token 配额能落地的前提）
- 启用审计日志（仓库已有 audit log 相关表与 UI 页面）
- 定期导出用量报表做对账

## 7. 企业版边界提醒

以下能力属于 `enterprise/`（混淆 whl），**不可汉化、不可修改**，方案不得依赖：

- SSO / SAML / OIDC 登录（控制台登录用社区版的用户名密码或自定义 auth 钩子）
- 部分高级审计与合规报表
- 部分高级路由与护栏能力

需要这些能力时，走「自建轻量替代 + 前置网关」路线，或单独评估企业授权。

## 8. 实施步骤

1. 盘点现有部署（当前状态、是否已上生产）与暴露面
2. 密钥治理：master key 替换、提供商 key 环境变量化
3. 数据库切换/加固 + 备份策略落地
4. 网络收敛：管理端点内网化、CORS 收敛、TLS 前置
5. 按 `docker-compose.hardened.yml` 出生产编排，双实例 + 共享 Redis
6. 上线前跑一次完整回归（见 10 号文档），含安全项检查清单

## 9. 验收标准

- [ ] master key 与所有提供商密钥均为环境变量注入，仓库内无明文
- [ ] 生产使用 Postgres，迁移演练记录完整，备份可用
- [ ] 管理端点与 UI 不对外网暴露
- [ ] 生产编排基于 hardened 基线，双实例 + 外部 Redis
- [ ] 健康检查探针配置生效
- [ ] 安全项自查清单全部通过
