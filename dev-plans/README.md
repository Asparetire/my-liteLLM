## 全局约束（所有文档共同遵守）

1. **上游同步能力不可破坏**：自有代码优先放新目录；必须改上游文件处统一加 `[CN-FORK]` 标记
2. **不可触碰清单**：API 字段名（`max_budget`、`tpm_limit` 等）、数据库列名、代码标识符、日志级别、异常类型名——全部保持英文
3. **企业版边界**：`enterprise/` 目录为混淆 whl，不得修改；自有功能不得依赖企业版 license 特性（SSO 等）
4. **Prisma 迁移红线**：只允许加 nullable 列，禁止 `UPDATE/DELETE/MERGE` 重写行（启动时同步执行迁移的硬约束，见上游 CLAUDE.md）
5. **代码规范**：遵循仓库 CLAUDE.md（无 AI 风格注释、Python 行宽 120、conventional commits、禁 Claude 署名）

## 全局验收（各文档验收之上的总闸门）

- `git merge --ff-only upstream/main` 在 main 上永远成功
- 全程 API 响应只增字段不改字段，老客户端零感知
- 后端 `make test-unit` 与 UI `npm run test:component` / `test:integration` 全绿
- 用户可见层面无 `$` / `USD` 字样（计费改造完成后）
